    <p class="product-kicker">Page Push · Privacy</p>
    <h1>Your browsing data goes where you choose.</h1>
    <p class="document-intro">Page Push has no account system, hosted backend, analytics, advertising, or telemetry. It sends page events only when you deliberately initiate a page push or run its connection test, and only to the HTTPS endpoint saved in your local browser settings.</p>

    <section class="document-section"><h2>What a manual push can include</h2><ul><li>Current page URL, title, and hostname</li><li>Timestamp and favicon URL, when available</li><li>Referring URL, when available</li><li>Selected text, when enabled and present</li></ul></section>
    <section class="document-section"><h2>What Page Push does not do</h2><ul><li>Does not operate a cloud service.</li><li>Does not route your browsing data through developer-operated servers.</li><li>Does not collect analytics, telemetry, or crash reports.</li><li>Does not automatically monitor browsing.</li><li>Does not execute remote code.</li><li>Does not send page events anywhere except the HTTPS endpoint you configure.</li></ul></section>
    <section class="document-section"><h2>What Page Push does not capture</h2><p>Page bodies, form contents, passwords, cookies, keystrokes, screenshots, and automatic browsing history are not captured.</p></section>
    <section class="document-section"><h2>Credentials and permissions</h2><p>Your endpoint configuration and optional authorization credentials are stored locally in browser storage. Page Push requests access only to the endpoint origin you approve. It does not synchronize these settings through a Page Push service.</p></section>
    <section class="document-section"><h2>Retention</h2><p>Page Push retains its settings and one compact last-delivery result in browser storage. It does not retain a local history of pushed pages. Your chosen endpoint controls any data it receives.</p></section>
    <section class="document-section"><h2>Removing data</h2><p>Removing the extension clears Page Push data stored in your browser. Data previously delivered to your endpoint is governed by that endpoint and must be removed there.</p></section>
    <section class="document-section"><h2>Website analytics are separate</h2><p>The Page Push extension does not contain website analytics. These Page Push pages do not load the analytics used elsewhere on krwill.xyz, and website analytics never receives pushed URLs, selected text, endpoint configuration, credentials, or delivery activity.</p></section>
    <section class="document-section"><h2>Contact</h2><p>Questions about Page Push or this privacy policy can be sent to <a href="mailto:support@krwill.xyz">support@krwill.xyz</a>.</p><p>Effective August 5, 2026.</p></section>
